新功能目录示例：`docs/features/F01-三种找座方案/`，仅维护《三种找座方案功能架构方案.md》和《三种找座方案功能代码实施方案.md》。先架构再实施，完成结果写回原实施方案；不再创建完成报告、新版/最终版副本。小修复更新原文件或PR说明。

本仓库已有基线、迁移和验证说明予以保留，不为追求目录形式批量重命名。新类别先在本索引登记，不造空报告或大量 .gitkeep。业务需求按用户提供的最新报告确认后导入，不把上游文档或参考仓库的问答范围当成本项目要求。

正式需求及课程报告是独立交付，不能被两份功能方案替代。图模型源与导出保持编号对应；报告以必要段落引用证据，不复制完整聊天、测试日志或真实学生隐私。未执行的验证写未验证，人工取舍只记录真实发生的内容。

上述约束原文于2026-10-29从用户提供的同名文件逐字节保存，作为仓库可访问的参考基准，不等同本组已经填写的报告。需求及后续修订必须按原文实际适用条款核对；具体执行与变更边界统一见根AGENTS.md。替换约束须有用户指定的新基准，原文中的教学示例、建议数量和B5条件不自动转成业务需求。
