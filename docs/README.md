# 文档索引与唯一来源

| 位置 | 用途 |
|---|---|
| 根 README.md | 系统入口、运行与 PostgreSQL 连接说明 |
| AGENTS.md | 智能体规则唯一入口 |
| CONTRIBUTING.md | Git、PR、审核流程及外部设置边界 |
| docs/团队分工.md | 成员身份、真实路径与共享范围 |
| docs/BASELINE-v1.0.0-postgresql.md | 首个 PostgreSQL 基线，标签固定，不覆盖其历史含义 |
| docs/MIGRATION.md | 当前迁移事实与需求差距，原位更新 |
| docs/VALIDATION.md、docs/evidence/ | 实际验证范围、关键脱敏证据及索引 |
| docs/features/Fxx-名称/ | 每项功能的架构方案和代码实施方案 |
| docs/templates/ | 上述两份模板，不作为已执行结果 |
| docs/requirements/ | 后续正式导入和确认的本组需求及图模型，按需创建 |
| docs/reports/ | 课程要求的报告和导出，按实际阶段创建 |
| docs/upstream/、diagrams/ | 原作者参考资料，非本组需求和完成报告 |
| work/、.local/ | 本地草稿、完整日志、运行配置，不提交 |

新功能目录示例：`docs/features/F01-三种找座方案/`，仅维护《三种找座方案功能架构方案.md》和《三种找座方案功能代码实施方案.md》。先架构再实施，完成结果写回原实施方案；不再创建完成报告、新版/最终版副本。小修复更新原文件或PR说明。

本仓库已有基线、迁移和验证说明予以保留，不为追求目录形式批量重命名。新类别先在本索引登记，不造空报告或大量 .gitkeep。业务需求按用户提供的最新报告确认后导入，不把上游文档或参考仓库的问答范围当成本项目要求。

正式需求及课程报告是独立交付，不能被两份功能方案替代。图模型源与导出保持编号对应；报告以必要段落引用证据，不复制完整聊天、测试日志或真实学生隐私。未执行的验证写未验证，人工取舍只记录真实发生的内容。
