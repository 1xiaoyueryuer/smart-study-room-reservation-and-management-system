### 1.3 范围与相关人员

包含图书馆、教学楼等实际纳入管理的自习空间，具体清单由管理员维护；不推定所有教室均可预约。角色为普通用户（本校学生、教职工，同规则）和学校统一管理员，不设置区域管理员层级。

普通用户提出和核对使用需求；统一管理员这一拟定业务角色维护资源、处理投诉及违规；第11组确认本项目需求设定；任课教师按课程要求验收。真实校方管理确认尚待开展。

需求分析阶段产物为三份Markdown报告、可编辑模型源说明与清晰图件、纸面页面草图、追踪及走查记录。开发迭代在原项目实施所述业务功能，真实校园认证、物理到场检测、摄像头或闸机集成、短信邮件和生产部署仍不因本次授权自动纳入。S07关闭旧候补递补及座位属性偏好自动分配的新增入口，保留历史查询；座位属性字段仅保留所需展示与溯源，不作为新增偏好分配入口。不单设续约与暂离计时。

### 2.2 详细用例

#### UC-01 比较方案并预约座位

参与者：学生或教职工；触发：准备找座学习。前提：账号可用，用户选择D至D+2的日期，空间与座位已维护。

1. 选择空间、日期和方案；第三种方案输入不少于30分钟的需求。
2. 系统从开放安排中扣除有效预约、本人重叠安排和停用时段，计算符合最短时长的连续可用空档。
3. 显示位置、编号、可预约起止、连续时长和等待时间。相同条件下图与列表使用同一数据口径。
4. 用户确认起止时间，系统重新核对资格、日期、开放、最短时长及座位与本人时间冲突。
5. 成功生成唯一有效预约，状态待签到，告知签到期限及取消规则。

异常：无结果说明原因，不擅自改变日期或场所；另一用户先约则明确提示冲突，不产生有效预约；失效账号或限制期拒绝。结果：成功占用所选时段；失败保持此前记录。规则BR-02—BR-06、BR-16。验收AC-01—AC-03、AC-07—AC-09、AC-13。使用频率待确认。

#### UC-02 按约签到并结束使用

参与者：预约本人、系统；触发：到场签到或期限到达。前提：本人有效预约、正确座位码。

1. 开始前可取消，不记违规；开始后尚未签到主动放弃则结束并登记一次违约。
2. 从预约开始时刻至开始后15分钟之前，核对本人、预约、座位后签到，转使用中。
3. 使用中可提前签退，记录时间并释放余时；到原定结束时刻系统自动结算，不处罚漏点签退。
4. 到签到期限仍未签到则未使用结束，释放余时、计一次未签到违约；重复检查不再计同类事件。

异常：开始前、15分钟届满、错误座位、他人预约或终止预约拒绝签到；故障或被占导致异常，按UC-03/UC-04核实纠错，终止预约不自动恢复。短暂离开不延长结束时间。规则BR-07—BR-11、BR-19。验收AC-10—AC-12。触发规律为每次预约及对应系统期限；实际频率待确认。

#### UC-03 座位被占求助与核实反馈

参与者：预约本人、统一管理员、被核查的现场人员；触发：发现预约座位被占。前提：用户能关联本人预约并描述情况。

1. 用户提交问题类型与情况，系统关联座位、预约和报告时间，照片可选。
2. 管理员受理并记录处理人，检查预约是否有效、双方是否弄错座位或时段，并核对现场情况。
3. 确属占用他人有效预约座位时要求纠正，引导合法预约其他座位。配合则提醒留记录；拒不配合须核实身份和事实后计违规；拒绝提供身份时记录“身份待核实”，继续现场协调，必要时转交校内有权限的现场负责人（承接岗位与联系方式待业务方确认），不猜测处罚对象。
4. 管理员填写结果反馈，用户看本人进度，可确认或补充异议。

异常：未查实不直接记违规；身份未知只保留事件，不猜测归属；自行解决可说明，未受理撤回与后续异议细节按状态草稿审阅；受理超时标记提示。被占导致错过签到可核实纠错，但提交投诉本身不延长签到期限。成功结果是留下核实与处置反馈，现场实际恢复依管理执行。规则BR-01、BR-12—BR-14、BR-19。验收SC-04、AC-05—AC-06、AC-16。发生频率待确认。

#### UC-04 违规累计限制与申诉纠错

参与者：系统、用户、管理员；触发：有效违规生效或用户提出申诉。前提：有可追踪的违规类型、时间、对象和依据。

1. 系统统计当前处罚周期30天内有效且未撤销违规，3次触发7天限制，通知原因与截止。
2. 禁止新预约；已有未签到预约管理取消并通知，不新增违约；使用中可到原结束。
3. 用户在违规通知后7天内申诉，管理员核对并反馈；成立则撤销误记违规、重算次数及相关限制，保留原始依据。
4. 限制到期恢复，旧违规不重复触发下一周期；手动加入、解除须有已核实理由、操作人与截止时间。

异常：有多个独立限制时，只解除符合纠错条件的限制；仍有有效限制则不能新预约。已取消预约不自动恢复，不能挤占他人后续预约。拒绝过期申诉或说明其他协助渠道，具体管理员例外受理另行决定。规则BR-14—BR-19；限制期间新违规纳入恢复后的新周期，旧处罚事件不重复使用。验收AC-14—AC-16。触发规律为违规生效、期限到达和申诉；实际频率待确认。

#### UC-05 资源停用及预约善后

参与者：统一管理员、受影响用户；触发：座位停用、空间关闭或开放时间缩短。前提：管理员有全校纳入管理资源权限，已有资源和预约记录。

1. 管理员选择资源、变更及原因，系统先列受影响预约和使用情况。
2. 确认后使资源或时段不可约，按管理原因取消受影响预约，保留记录并通知，不记用户违约。
3. 使用中人员也收到通知，由管理员现场协调，记录管理原因终止。
4. 恢复开放后重新可约，不自动恢复原取消预约。

异常：管理员未确认则不执行影响性变更；无权限拒绝；更新或通知失败应明确显示未完成和待处理，不能声称善后完成。规则T2、T3，详细审计与补偿方式为分析细化。验收SC-06、AC-17。频率按维护事件触发，待确认。

## 3 领域与数据

### 3.1 术语

自习空间为被纳入预约管理的房间或区域；座位为最小预约资源。“半空闲”是现有平台相对于选定时间段部分可约的标签（FACT-01），不等于暂离，也不直接作为新系统固定物理状态。预约状态、可预约空档、签到记录所反映的使用情况、真实物理占用必须区分。

违约为违规记录中的自动业务类型；提醒单独记载、不计违规次数。有效违规为已生效且未撤销记录。黑名单在本项目表示有起止与原因的预约限制。申诉纠错不自动恢复已终止预约。受理表示管理员接手核查，不等于现场解决。

### 3.2 数据字典

需求阶段说明业务含义与来源，不提前规定数据库类型或索引。

| 对象 | 关键数据与含义 | 来源及约束 | 维护与访问 |
|---|---|---|---|
| 用户 | 校园身份标识、显示名、学生/教职工/管理员角色、启用状态、联系方式 | 校园身份由管理维护；原型仅模拟，身份标识唯一 | 本人改联系方式；管理维护身份角色，普通用户不看他人私密信息 |
| 自习空间 | 名称、楼栋、楼层、位置、开放安排、启停用、容量 | 管理录入，容量按有效座位计算；模拟名不当真实清单 | 管理维护，用户查开放与位置 |
| 座位 | 编号、所属空间、位置、启停用原因 | 空间内编号唯一，归属一个空间；停用不删历史 | 管理维护，用户看可预约信息 |
| 预约 | 编号、本人、座位、日期起止、创建时间、状态、终止原因 | 用户提交与系统校验形成，受日期、最短时长、开放与冲突规则限制 | 本人操作查询；管理按职责查询善后 |
| 使用记录 | 关联预约、签到、签退或自动结束、补签依据及操作时间 | 一次预约至多一条有效使用记录；不证明物理到场检测 | 本人看自身，管理处理核实 |
| 提醒 | 关联事件、事实说明、对象（已知时）、处理人和时间 | 配合纠正等情况产生，不计违规 | 管理记录，相关本人看允许范围 |
| 违规 | 类型、关联预约/事件、用户、事实依据、登记来源与时间、有效/撤销、纠错原因 | 自动未签到/放弃，手动核实拒不配合；同类事件不重复计次 | 本人查询申诉，管理核查；原始依据不抹除 |
| 投诉 | 类型、本人、相关座位预约、说明、可选材料、时间、状态、处理人 | 本人提供；占座求助关联本人预约，一般服务投诉可不关联预约；用户不必自行知道占用者身份 | 本人看本人，管理受理全校纳入范围 |
| 反馈 | 关联投诉、结果说明、依据、处理人与时间、后续异议 | 管理核实后生成，可多次补充保留过程 | 投诉本人及管理查看 |
| 预约限制 | 来源、起止、原因、支持违规、有效/到期/解除、操作者 | 自动累计或手动核实；多个独立限制可并存 | 本人看自身原因期限；管理维护留记录 |
| 申诉 | 本人、关联违规、理由材料、提交时间、审核结果及依据 | 通知后7天内；待审不等于违规已撤销 | 本人提交查询，管理审核 |
| 评价 | 关联预约空间、本人、1—5星、文字、更新时间、管理回复及隐藏原因 | 实际签到并完成后每预约一条，可改本人内容；不改他人分数 | 本人维护，公开不暴露身份标识，管理留理由处理 |
| 消息与日志 | 收件人、业务对象、说明、时间；操作人、动作、结果与原因 | 站内通知与关键动作自动生成 | 本人只看本人消息，管理按职责看审计 |

### 3.3 统计口径

预约次数按成功创建日期计，取消后保留历史并另列取消数；无效提交不计。签到人次按有效签到记录计，不称去重人数。时长按签到至签退或原结束时刻推算、跨日切分，不等同于真实停留时长。有效违规不含提醒及已撤销记录。投诉待办为待受理与处理中，待确认反馈单列。若展示使用比例，分母为当前开放且未停用座位，分母为0显示不适用。

## 5 行为与状态

预约状态：待签到（含尚未开始）、使用中、已取消、未使用结束、已结束。违规有效性独立于预约终止，撤销违规不自动使预约复活。资源停用或缩短开放时间影响待签到预约时，确认后管理取消（ST-13）；影响使用中预约时，按管理原因取消并由人现场协调（ST-12）。

投诉草稿：待受理、处理中、已反馈待确认、已结案、已撤回；未受理可撤回、反馈后补充异议可继续核查；每次处理反馈发出后给予7×24小时确认期，截止前本人确认走ST-23、提出异议走ST-25；截止时仍无确认或异议才自动结案（ST-26）。限制记录：生效中、已到期、已解除；多个有效限制独立存在，单条解除不隐式清除其他条。
