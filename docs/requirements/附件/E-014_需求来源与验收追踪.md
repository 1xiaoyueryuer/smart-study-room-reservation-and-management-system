## 关键边界验收点

| 编号 | 条件 | 预期 |
|---|---|---|
| AC-01—AC-03 | E-012 P-01的三个空档 | A最早、B最长、C满足2小时且最早 |
| AC-04 | 同一条件切换图列表 | 编号、可约时段及条件一致，不能只靠颜色 |
| AC-05—AC-06 | 核实占座后配合/拒绝纠正 | 提醒不计违规；拒绝须核实身份事实后登记 |
| AC-07 | D、D+1、D+2、D+3 | 前三天通过日期校验，D+3拒绝 |
| AC-08 | 单次29、30、241、300分钟 | 29拒绝；其余在开放、无冲突等条件满足时允许，不设4小时上限 |
| AC-09 | 座位或本人重叠与首尾衔接 | 重叠拒绝，衔接不因边界相等而拒绝 |
| AC-10 | 开始、14分59秒、15分整签到 | 前两者可通过时间校验，15分整超时 |
| AC-11 | 同一未签到预约重复超时/放弃 | 同类违约只一条 |
| AC-12—AC-13 | 提前签退；当天已约4小时再约其他不重叠时段 | 提前释放剩余时段；不因当天累计4小时拒绝新预约 |
| AC-14 | 当前周期第3次有效违规 | 7天限制，未签到管理取消且不多计，使用中至原结束 |
| AC-15 | 误记第三条撤销且无其他限制 | 重算解除，不自动恢复已取消预约 |
| AC-16 | 原时段已释放并被他人预约后要求补签 | 不恢复冲突预约，误记违规可纠正 |
| AC-17 | 停用有预约/使用中的资源 | 先列影响、确认后管理取消通知、不误罚、现场协调 |
| AC-18 | 查询他人私密记录 | 拒绝且状态保持；纸面仅推演 |
| AC-19 | 统计刷新失败、分母为0 | 保留旧值及时间、失败可见；比例不作除零 |
| AC-20 | 未签到未完成就评价、重复评价 | 不满足资格拒绝；同一预约只维护一条 |
